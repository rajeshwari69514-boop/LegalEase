# ⚖️ LegalEase

AI-Powered Legal Document Generator

## 📌 Description

LegalEase is an AI-powered application that helps users generate legal document drafts based on the information they provide.

The application uses Google Gemini AI to generate structured legal document content and allows users to download the generated document as DOCX or PDF.

## ✨ Features

- Generate legal document drafts using AI
- Support for multiple document types
- User-friendly Streamlit interface
- FastAPI backend
- Google Gemini AI integration
- Document preview
- DOCX export
- PDF export
- Input validation
- Legal disclaimer

## 📄 Supported Documents

- NDA
- Employment Contract
- Lease Agreement
- Service Agreement

## 🛠️ Technologies Used

- Python
- Streamlit
- FastAPI
- Google Gemini AI
- python-docx
- FPDF2
- Requests
- python-dotenv
